- **Java:** Construção de APIs RESTful robustas, manipulação de endpoints e arquitetura limpa.
- **Spring Boot:** Desenvolvimento ágil de microsserviços e aplicações web corporativas.
- **Python:** Automação, scripts e lógica de programação.

#### **DevOps & Banco de Dados**
